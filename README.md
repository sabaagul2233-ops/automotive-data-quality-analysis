

# Automotive Data Quality Analysis

## Project Overview
This portfolio project demonstrates data quality validation and analysis using Python, Pandas, and SQL on synthetic automotive data.

## Project Objectives
- Identify missing values and duplicate records.
- Validate vehicle identification numbers (VINs).
- Detect incorrect prices, mileage, and manufacturing years.
- Document data quality issues.
- Generate cleaned datasets and quality reports.

## Tools and Technologies
- Python
- Pandas
- SQL
- CSV and JSON
- GitHub

## Project Workflow
1. Load the automotive dataset.
2. Inspect records and identify data quality issues.
3. Apply validation rules.
4. Document errors and discrepancies.
5. Export valid records and a quality summary.

## Project Files
- vehicles_raw.csv — synthetic automotive dataset
- quality_checks.py — Python validation script
- data_quality_checks.sql — SQL quality checks
- issues.csv — identified data issues
- vehicles_valid.csv — records passing validation
- summary.json — data quality summary
- test_quality_checks.py — automated tests

## Data Source
Synthetic practice data created for portfolio demonstration. No real customer or confidential vehicle records are used.
